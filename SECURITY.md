# Security Policy

## Report a Vulnerability

Use this repository's private GitHub Security Advisory reporting flow. Do not open
a public issue for a suspected credential exposure or exploitable skill behavior.

Include the affected skill and revision, the risky instruction or file, expected
impact, and a minimal reproduction that contains no real credentials or private
data.

## Scope

Validation checks structure, links, shell syntax, executable bits, and common
secret signatures. It does not execute bundled skill scripts and is not a sandbox,
malware scanner, or proof that an instruction is operationally safe.
